# Security

If you believe you have found a security issue in a ypbin project, please report it **privately** to `security@ypbin.cn` and include the affected version, reproduction steps and the impact you observed. Do not disclose an unpatched vulnerability in a public issue.

Security contact details are also published at [`/.well-known/security.txt`](/.well-known/security.txt). We do not currently commit to a fixed response SLA; reports are triaged and handled according to their impact, and verified fixes land through the normal [release process](/en/releases).

For the security posture of the products — authentication and identity-header handling, internal token guards, and the relevant starter modules — see [Architecture](/en/architecture) and the security-related sections of the [Docs center](/en/guide).
