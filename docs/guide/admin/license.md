# 商业授权教程

ypbin-admin 是授权供应方管理台，ypbin-starter-license 是消费端运行时。两端职责和密钥必须严格分离。

## 准备签发密钥

在授权管理页调用“生成密钥”，系统一次性返回 SM2 公钥、SM2 私钥和 SM4 密钥。生成结果不落库。

签发端配置：

```text
LICENSE_ISSUER_PUBLIC_KEY
LICENSE_ISSUER_PRIVATE_KEY
LICENSE_ISSUER_SM4_KEY
```

私钥只能留在签发端；消费端只获得公钥和交付所需的 SM4 密钥。生产环境不得复用开发密钥。

## 授权生命周期

```text
DRAFT → PENDING → ISSUED → REVOKED
          └──────→ REJECTED → DRAFT
```

1. 创建人保存草稿；
2. 提交后进入待审批；
3. 另一位平台管理员审批；
4. 通过后生成授权串并创建或复用开放应用；
5. 按 CODE 或 FILE 模式交付；
6. 必要时吊销，联机消费端可感知。

审批人不能与创建人相同，避免单人完成高风险签发。

## 授权内容

授权可约束被授权方、生效时间、到期时间、宽限期、机器指纹、租户、功能模块、业务额度和扩展属性。额度只声明上限，实际计数仍由消费端业务维护。
